How a document is guarded

Every file picks its own terms.

Set access per document, not per vault. A payslip can stay public inside a shared folder while your passport demands a one-time code.

01 · PUBLIC

Open on scan

No gate. Anyone with the link or QR sees it immediately — for documents that were never sensitive to begin with.

02 · CODE

Access code

A short code you hand out separately from the link, hashed the same way as your vault password.

03 · ONE-TIME

Single view

The link burns itself after one open — granted atomically, so two people can't both slip through on the same instant.

04 · EXPIRING

Time-boxed

Set an expiry in hours. After it passes, the gate shows "expired" — no need to remember to revoke it.

05 · LIMIT

Capped views

Allow exactly N opens, then the document quietly stops answering the door.

06 · PASSWORD

Vault password

Requires the same master password that guards the whole folder — for documents that should stay with the family.
